# 🏏 IPL Data Analysis (Python + Pandas)

## 📌 Project Overview
This project analyzes IPL match data to extract meaningful insights about team performance, players, and match trends using Python.

## 📊 Dataset
- Total Matches: 577
- Source: IPL Matches Dataset (CSV)
- Key columns used:
  - winner
  - player_of_match
  - city
  - toss_decision

## 🔍 Analysis Performed
- Identified teams with the highest number of wins  
- Found top players with most "Player of the Match" awards  
- Analyzed toss decisions across matches  
- Explored cities hosting the most matches  

## 📈 Visualization
- Created bar charts to compare top-performing teams  
- Used horizontal bar graphs for better readability  

## 🛠️ Tech Stack
- Python  
- Pandas  
- Matplotlib
